\# FORGE // Industrial AI



\*\*Predictive maintenance and industrial fleet monitoring using machine learning.\*\*



FORGE is a Python-based industrial AI project for exploring sensor-driven machine failure warnings, model evaluation, and operational monitoring through an interactive Streamlit dashboard.



\## Project capabilities



\- Sensor-data preparation and feature engineering

\- Logistic regression baseline for predictive maintenance

\- Chronological train, validation, and test evaluation

\- Validation-based classification threshold selection

\- Leakage-aware temporal splits with a purge interval

\- Sensor-failure stress testing

\- Automated tests for prediction behavior, feature safety, and synthetic failure-label boundaries

\- Interactive Streamlit application for exploring model predictions



\## Technology stack



\- Python

\- pandas

\- scikit-learn

\- Streamlit

\- pytest

\- Ruff



\## Getting started



\### 1. Clone the repository



```bash

git clone https://github.com/RajasJoshi05/industrial-ai-vision-maintenance.git

cd industrial-ai-vision-maintenance

```



\### 2. Create and activate a virtual environment



Windows PowerShell:



```powershell

python -m venv .venv

.\\.venv\\Scripts\\Activate.ps1

```



\### 3. Install dependencies



Install the project's declared dependencies using the repository's dependency file and instructions. If a `requirements.txt` file is present:



```powershell

pip install -r requirements.txt

```



\### 4. Run the application



```powershell

streamlit run app.py

```



The application may require the model artifacts generated by the project's training workflow. Follow the repository's training instructions if those artifacts are not available locally.



\## Testing and code quality



Run the test suite using:



```powershell

pytest

```



Run Ruff checks using the project's configured Ruff commands.



\## Data and evaluation disclaimer



\*\*The current dataset is synthetic.\*\* Evaluation metrics demonstrate the behavior of the model and evaluation pipeline on synthetic data; they do not establish real-world industrial predictive performance.



Before operational deployment, the model requires evaluation on representative real-world sensor data, validation under production conditions, and an appropriate monitoring and maintenance process.



\## Repository hygiene



Generated datasets, trained model artifacts, and local virtual environments are excluded from version control. Reproduce them locally using the project's data preparation and training workflows.
